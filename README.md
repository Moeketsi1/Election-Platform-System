# Election Platform – Prototype System (PSystem)

### Overview
In today’s interconnected digital landscape, enhancing the democratic process through secure, accessible, and transparent technologies is crucial. The Election Platform Prototype System (PSystem) is a web application designed to simulate an inclusive, scalable, and real-time online election system. Built with a modern tech stack using Firebase, object-oriented principles, and a visually engaging frontend, this prototype demonstrates key features of digital voting platforms.

#### Key Features

  *  Role-Based Access Control

      *  Guest: View real-time election results without registering

      *  Registered Voter: Secure sign-up, one-time voting access

      *  Election Commission (Simulated): Candidate setup from database

*  Authentication & Verification

    *  Firebase Authentication

    *  Email validation using MailCheck.ai to block disposable emails

*  Voting & Results

    * One-time vote per user restriction

    *  Live polling dashboard with candidate percentages

    *  Realtime Firestore updates with transaction handling

*  Data & Database

    *  NoSQL Cloud Firestore for dynamic and scalable data management

    *  Real-time vote tally, total vote count, and participation percentage

*  Security

    *  Encrypted authentication

    *  Email verification

    *  Duplicate vote protection
