This Online Election Platform project is a versatile web application designed to facilitate an inclusive
and transparent electoral process. It provides users with the ability to register their personal details 
and login to the application to cast their votes. Registered voters can seamlessly login, providing their email
and set password for real-time verification, ensuring the eligibility to cast their votes.
As votes are casted, the platform dynamically updates and displays the latest poll results in real-time, fostering transparency and engagement. 
The user interface is intuitively designed for both administrators and voters, promoting a streamlined
experience. Security measures, including robust authentication protocols, protect against
unauthorized access.
